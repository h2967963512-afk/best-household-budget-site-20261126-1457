HomeBudget is a working household budget site for one family: a dashboard with income, spending and balance that add up, editable monthly budgets, a transaction ledger that updates every total, savings goals, and a bills list with due dates — all in plain static files with no network requests.

## Run it

```sh
python3 -m http.server --directory app 8080
```
